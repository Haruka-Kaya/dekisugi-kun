# Next Gen 審査に合わせた提出設計（2026-10-01確認）

対象は RevenueCat Shipaton 2026 の **Next Gen Award**。一般枠のストア公開・
売上実績の条件を、この学生枠の必須条件として混ぜない。

## 公式の基準と審査方法

[公式規約 §6](https://revenuecat-shipaton-2026.devpost.com/rules)は、
アイデアの価値・実装の進展・RevenueCatの使い方・技術とプロダクトの判断という
4点を列挙している。比重は公表されていない。同点時は、適用する基準の列挙順に
比較する規定がある。冒頭で対象と独自性を示すのは、これを踏まえた編集判断であり、
冒頭を変えれば勝てるという公式の保証ではない。

[主催者の審査説明（2026-06-26）](https://www.shipaton.com/blog/how-we-judge-shipaton)
によると、必要項目の確認後、少なくとも2人のRevenueCat担当者が予備審査し、
動画の最初の2分と提出文を確認する。審査員が文面・動画・画像を見て基準別に
1〜5で評価し、推薦候補を主催者側が最終検討する。この記事は大会全体の工程説明で、
変更の可能性がある。Next Gen担当者の個別割当や非公開の採点比重は推測しない。
一般枠向けのストア確認より、Next Genの公式例外を優先する。

Next Genは動画と**公開OSSリポジトリ**で審査され、ストア公開は不要。
動画は2分以内、YouTubeかVimeoで公開し、対象端末で動くアプリを見せる。
1024角アイコンと、端末フレームなし1179×2556のアプリ画像も必要。
在学生の資格、学術メール、未成年の場合の保護者同意は本人側の確認が残る。
[公式規約](https://revenuecat-shipaton-2026.devpost.com/rules)、
[学生枠の説明](https://www.shipaton.com/next-gen)。

## 今回の反映

| 基準 | 動画・提出物で示す内容 |
|---|---|
| アイデア | 冒頭から「教えることで理科を学ぶ」体験を実画面で示す。対象や背景は英語提出文と審査ガイドで補う |
| 実装 | 実際の予想、教材、教材を隠した説明、固定質問、ヒント、言い直し、未解決の記録を56.1秒で通す。入力・選択・スクロールの録画を主役にする |
| RevenueCat | Native Test Storeの購入完了と実際の着せ替え・保護者レポート。必修学習を有料化しない理由も述べる |
| 判断・丁寧さ | 端末内の必修学習、対等な文字経路、外部AI採点を使わない判断、MITコードへの短い英語導線、実キャプチャと編集の再現性 |

提出文はDevpostの欄ごとに整理し、旧ブラウザデモや未提供AI特典の記述を除いた。
現行のスクリーンショットを指定サイズで直接撮影し、旧UIを応募の入口から外した。
復習対象を「訂正済み」と偽ったり、n=18の誘発調査を学習効果と扱ったりしない。

v10は長い説明スライドを実操作中心の56.1秒へ再編集した。同時刻の録画から
拡大表示を作り、静止画はヒントと書き直した説明の計3.6秒、締めは2.2秒だけ。
学習録画はv8の実操作を再利用し、Plusは別の成人テストプロフィールで撮り直した。

## 提出直前の確認

- 公開リポジトリとMIT認識。匿名アクセスでも本文・素材を読めること。
- 公開YouTube/Vimeo URL。ローカルMP4の完成は動画公開・応募完了とは別。
- Devpost下書きに英語文・画像・動画URL・Next Gen選択・package IDを反映。
- 学生資格・学術メール・保護者同意（該当時）。資格をコードから推定しない。
- 最終動画を再生し、音声を含めて確認。エミュレーター検証を物理端末QAと呼ばない。
- 締切前の提出完了表示を確認。下書き保存は提出ではない。
