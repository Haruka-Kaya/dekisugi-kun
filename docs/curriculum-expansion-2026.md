# デキすぎ君 — 中学理科カリキュラム拡張計画

## 正本

教材範囲は、文部科学省「中学校学習指導要領（平成29年告示）解説 理科編」を正本とする。
現行アプリの誤概念カタログだけから単元を増やさず、同解説が示す第1分野（物質・エネルギー）と
第2分野（生命・地球）の両方を扱う。

- [学習指導要領・解説の公式一覧](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)
- [中学校学習指導要領解説 理科編 PDF](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_005.pdf)

## 現在地

catalog schema v10では、従来の力学・圧力／浮力・電流／磁界4単元11概念に、
身の回りの物質・生物の体・天気の変化・大地と宇宙の4単元12概念を加えた。
合計は8単元23概念で、第1分野と第2分野の両方にproduction Pathを持つ。

各概念は同じ正本から、Learn、Diagram、固有Story、Listening、Teach-back、Boss、
foundation / conditions / transfer、Notation、canonical Repairを生成する。これは第1段階の
領域横断を完了したという意味であり、中学理科の全単元を網羅したという意味ではない。
科学技術と自然環境は次段階に残る（化学変化・イオン・生命の連続性は段階2として実装済み）。

## 拡張順

最初に4領域をまたぐ縦切りを作り、その後に学年内の系統を埋める。

| 段階 | 単元 | 最初の固定概念 |
|---|---|---|
| 1 | 身の回りの物質 | 密度、気体の性質、状態変化と質量 |
| 1 | 生物の体 | 細胞、光合成と呼吸、消化・吸収 |
| 1 | 天気の変化 | 湿度と雲、前線、気圧配置と風 |
| 1 | 大地と宇宙 | 地層、火山・地震、日周運動と季節 |
| 2 | 化学変化と原子・分子 | 化合・分解、酸化・還元、質量保存 |
| 2 | 化学変化とイオン | 電解質、酸・アルカリ、中和と電池 |
| 2 | 生命の連続性 | 生殖、遺伝、進化 |
| 3 | 科学技術・自然と人間 | エネルギー変換、資源、災害と環境の意思決定 |

## 1概念の受入条件

単元名と説明文を追加しただけではproduction教材としない。各概念は同じcatalog正本から、
次をすべて生成・検証する。

1. 教材本文、家庭または教室で安全にできる観察、固定checkpoint。
2. foundation / conditions / transferの3課題。場面、期待結果、理由を1対1で対応させる。
3. single select / classify / sequenceのうち最低2種類を3周で使う。
4. 固定人物による固有Science Story。選択別反応、科学的解決、短い落ちを持つ。
5. 記号・モデル・順序・グラフを扱うNotation。物理の矢印や式を無理に流用しない。
6. 教材を隠して音声または文字で説明し、stageごとの固定問い返しへ答えてから説明を
   言い直すTeach-back。自由説明を自動採点せず、全文や録音を保存しない。
7. 誤答本文と選択肢IDから独立したcanonical need code。exact Repair成功でだけ解消する。
8. Learn → Diagram/構造操作 → Story → Listen → Speak → Bossの必修PathとUnit末Legendary。
9. 320×568・文字200%、light/dark、両OS Reduce Motion、48dp、Semantics。
10. server正本、公開API、同梱asset、Dart厳格parserの完全一致と未知field fail-closed。

## 安全境界

- 家庭用コンセント、危険な薬品、火気、密閉加熱、人体を使う危険な実験を生徒単独課題にしない。
- teacher-required課題は家庭実施の代替観察を必ず持つ。
- 自由記述、録音、ASR全文、選択内容、反応時間を保存・送信しない。
- 生物・環境の課題を成績、診断、健康判断へ使わない。
- 実験結果が条件で変わる場合、成功例だけを正答にせず、測定条件と限界を明記する。

## 完成判定

第1段階の4単元は実Pathへ接続し、既存物理単元と同じ保存・復習・heart・Repair契約を通す。
ただし残る段階2・3を実装し、全領域の授業順と所要時間を教員pilotで確認するまでは、
「中学理科全範囲を完成」と表示しない。学習指導要領への対応表や自動テストだけで
学習効果を断定せず、初見学習者と教員による内容・語彙・安全性の確認を別gateにする。
