> [!danger] 現在、外部AI・学校サーバを使う学校導入を進めないでください
> Google Cloud Service Specific Terms §20(d) は、18歳未満向け、または18歳未満が
> アクセスする可能性が高いオンラインサービスでの生成AI利用を禁止しています。
> 旧研究コードの Vertex AI API / Vertex AI Live API も対象です。現行productionの必修学習は
> これらへ接続しませんが、将来再接続する場合も同じ禁止を受けます。
> 年齢ゲート、学校の承認、保護者同意では解消しません。

このフォルダの契約・同意資料は、AI 基盤の移行後に再レビューするための**作業中資料**です。
外部AI版の学校提案、保護者同意の取得、コード配布、授業・実証には使わないでください。
通信しない端末内モードは別の最小構成として実装済みですが、学校の情報セキュリティ確認と
exact buildの通信監査を終えるまで、学校導入済みとは扱いません。

## 通信しない端末内モード

現在のアプリには、年齢や越境送信の同意を保存せず、同梱教材だけで進む経路があります。

- 外部AI、学校Team API、RevenueCat、端末ID登録へ接続しない
- 同梱教材を読み、見ずに思い出し、条件・理由と具体場面を足す
- 固定された思い込みの3択を、誤答ヒントを使って直す
- 自由記述と選択した答えは送信・保存せず、自動採点・習得認定・成績利用をしない
- 次の練習を選ぶため、教材ID・概念ID・進行、canonical need、heart、完了日時、XP・結晶・questなどの
  冪等な報酬台帳を端末内に保存する。音声PCM、自由文、ASR候補、選択肢ID、誤答本文は保存せず、
  学習履歴は画面から削除できる

学校で試す前には、学校所有端末のクリーンインストールと機内モードでこの境界を実査し、
MDM、共有端末初期化、アクセシビリティ、対象学年・授業時間、先生の支援方法を確定します。

## 学校コードの現在の実装

以前の資料にあった、端末内だけで判定する自由入力の「あいことば」は現行実装と一致しません。
現在の学校コードはサーバーが発行する8文字の招待コードです。

- コードは端末からサーバーの `/api/team/join` へ送信される
- 同時に端末トークンが送られ、サーバーでは端末由来 ID を HMAC 変換したメンバー ID と紐づける
- コードは、学校が案内したチーム経路を確認するためのもの
- **保護者同意、学校承認、契約締結の証跡ではない**
- 現在は学校経路自体を UI で遮断しており、コードの入力・送信はできない

学校コードを再開する場合、学校向け説明、プライバシー表示、委託先・保存項目・保存期間・削除手順を
現行実装に合わせて再確認する。

## 再開前に必要な順序

1. 未成年向け利用が契約上可能な AI 基盤へ移行する、または個別契約を締結する
2. 学校設置者の情報セキュリティ・個人情報保護担当と、利用目的と責任分界を確認する
3. 委託先・再委託先、国外処理、保持、削除、事故通知、監査、SLA を契約書へ反映する
4. 学校一括契約、請求、組織・教員・生徒・座席の運用を実装する
5. 説明資料・同意書・アプリ表示・実装を再レビューする
6. 学校側の正式承認後にのみ、保護者説明と生徒利用へ進む

詳細は [`../age-restriction.md`](../age-restriction.md) と
[`../school-readiness.md`](../school-readiness.md) を参照してください。
