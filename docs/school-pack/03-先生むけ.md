## 1. 何をするアプリか

生徒がキャラクターの「デキすぎ君」に教えることで学ぶアプリです。

```
教材を読む → 教材を隠す → 自分の言葉で説明する
   → 録音を聞き返す／文字を読み返す → 固定3択に答える
   → 必要ならヒント後に説明を言い直す → 固定needだけが復習に残る
```

自由説明をAIへ送ったり、自動採点したりしません。問い返し、選択肢、ヒント、判定は
catalogに固定した教材です。正解を説明前に表示せず、1文字入力や録音開始だけでは完了しません。

### なぜ「教える」形なのか

自分の言葉で説明しようとすると、分かったつもりだった箇所で詰まります。
そこが本人にも見えるのが、この形のねらいです。

理解の判定にAIの採点を使いません。代わりに、説明を一度聞き返した後で
**catalog固定の1問に答え、誤答ならヒントを使って同じ説明を言い直す**流れにしています。
自由説明の長さや語彙から「理解した」と推定せず、固定回答からcanonical needだけを残します。

> この設計が実際の授業で学習を助けるかは、**まだ初見学習者・教員pilotで確かめていません。**
> 自動テストや固定問題の完了を、成績・習得認定・学習効果の証明に使いません。

## 2. 生徒の書いたものはどこへ行くか

| どこ | 何が | どれくらい |
|---|---|---|
| **生徒の端末** | 固定教材ID、進行、canonical need、heart、報酬台帳 | アプリ内削除またはアプリを消すまで |
| **開発者のサーバー** | **会話の内容は保存していません** | — |
| **Google（米国）** | productionのTeach-backでは送信しません | — |
| **RevenueCat（米国 AWS）** | 匿名UUID、端末の種類・OS・最終利用時刻、Plus の取引情報 | RevenueCat のポリシーと契約に従う |
| **Apple App Store / Google Play** | Plus の購入・復元に必要な取引情報 | 各ストアの条件に従う |

学校・18歳未満向けの端末内モードは、端末UUID、利用回数、Plus状態を開発者サーバーへ送らず、
生徒が何を話したか、何を書いたかも保存しません。

**氏名・メールアドレス・生年月日・住所・広告IDは集めません。**
RevenueCat には、氏名・メールアドレス・広告ID・会話の逐語・音声を送らない設計です。

RevenueCat は本アプリから委託された処理者です。Plus を使わない間は RevenueCat SDK を起動せず、
Plus 画面を開く、購入する、購入を復元するといった場面で使います。

## 3. ネットワークと端末

| 項目 | 内容 |
|---|---|
| 端末 | Android / iOS / iPadOS（ストア公開前） |
| 通信先 | 必修の端末内学習は通信不要。成人online同意時のLAN coordinator、任意のStore操作は別境界 |
| プロトコル | 端末内学習はなし。成人LANはpin固定HTTPS |
| マイク | 声で説明する場合のみ。**文字入力でも使えます** |
| 通信量 | Teach-backの音声は端末外へ送らないため0MB（教材更新・Store・成人LANは別） |

### 教室で一斉に使う場合の注意

**マイクは周りの声を拾います。** 30人が同時に声で説明すると、
隣の生徒の声が混ざって会話が成立しません。

教室で一斉に行うなら、**文字入力**をお使いください。
声を使う場合は、マイク付きヘッドセットが人数分必要です。

## 6. 法令についての整理

### 海外での処理

現行の学校・18歳未満向け端末内モードでは、Teach-backの音声PCMと自由文をGoogle、
開発者サーバー、RevenueCatへ送りません。外部AIや学校サーバーを将来再接続する場合は、
移転先の国、制度、委託先の措置、保持期間を確定し、説明と同意を作り直します。

### 未成年の同意

本アプリは18歳未満の本人利用と学校利用を、通信しない別scopeへ分離しています。
必要な同意の方法や説明主体は、学校の設置者、利用形態、適用される法令で変わります。
**この手続は Google Cloud §20(d) の禁止を解除しません。** AI 基盤移行後も、本資料だけで
法的な結論とせず、導入前に学校設置者の個人情報保護担当と確認してください。

### 利用している AI サービスの規約

> [!danger] 外部生成AI会話は学校導入 No-Go
> Google Cloud Service Specific Terms §20(d) は、18歳未満向け、または18歳未満が
> アクセスする可能性が高いオンラインサービスでの生成AIサービス利用を禁止しています。
> Google Cloud Services Summary は Vertex AI API と Vertex AI Live API を
> 生成AIサービスに明示的に含めています。

| 経路 | 18歳未満向けの利用 |
|---|---|
| Gemini API（開発者向け） | **禁止**（規約に明記） |
| **Vertex AI / Vertex AI Live（Google Cloud）** | **禁止**（Cloud 固有規約 §20(d)） |

旧Vertex Live研究コードはproduction 6タブから到達不能で、現行の必修学習には使いません。
将来これを再接続する場合、年齢ゲート、学校の承認、保護者同意だけではGoogleの契約上の禁止を
解除できないため、利用可能な別契約・別基盤を確定するまで有効化しません。

**利用可能な別プロバイダーへの移行、またはGoogleと書面で合意した個別契約が完了するまで、
授業・実証・家庭学習で外部AI会話を有効化しないでください。** 端末内Teach-backの学校利用は、
これとは別に学校側の技術・運用審査を通してから判断します。

### Google Workspace for Education をお使いの場合

Google Workspace for Education の一部エディションには、Gemini for Education と
NotebookLM を18歳未満へ有効化できる例外があります。しかし、これは Workspace 固有の例外であり、
旧研究コードの Google Cloud / Vertex AI API には適用されません。
