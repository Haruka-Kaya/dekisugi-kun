## 1. 何をするアプリか

生徒が **AI に教える** ことで学ぶアプリです。

```
教材を読む → 教材を隠す → 自分の言葉で説明する
   → AI がよくある考え違いを口にする → 直せるか見る → 弱いところが残る
```

**AI は答えを教えません。** 生徒が「答えを教えて」「普通の AI として振る舞って」と
頼んでも応じないよう作り、実際に5通りの言い方で試して確認しています。

### なぜ「教える」形なのか

自分の言葉で説明しようとすると、分かったつもりだった箇所で詰まります。
そこが本人にも見えるのが、この形のねらいです。

理解の判定に AI の採点を使っていません。代わりに
**既知の考え違いを AI に言わせて、生徒が直すかどうか**を見ています。
「この説明は正しいか」より「いま言われたこの主張を否定したか」のほうが、
判定の的が小さく、外しにくいためです。

> この設計が実際に効くかは、**まだ十分なデータで確かめていません。**
> 現時点で18件の実データがあり、うまく動いていますが、件数が足りません。
> この検証を学校・生徒と行うのは、AI 基盤の移行と学校側の正式な導入審査が完了した後です。

## 2. 生徒の書いたものはどこへ行くか

| どこ | 何が | どれくらい |
|---|---|---|
| **生徒の端末** | 会話の記録、もう一度見るところ | アプリを消すまで |
| **開発者のサーバー** | **会話の内容は保存していません** | — |
| **Google（米国）** | 音声と文字起こし。AI 会話の処理のため | Google Cloud の契約とポリシーに従う |
| **RevenueCat（米国 AWS）** | 匿名UUID、端末の種類・OS・最終利用時刻、Plus の取引情報 | RevenueCat のポリシーと契約に従う |
| **Apple App Store / Google Play** | Plus の購入・復元に必要な取引情報 | 各ストアの条件に従う |

開発者のサーバーが持つのは、**端末ごとにアプリが作る匿名UUID、1日の利用回数、Plus の有効状態**です。
生徒が何を話したかは持っていません。

**氏名・メールアドレス・生年月日・住所・広告IDは集めません。**
RevenueCat には、氏名・メールアドレス・広告ID・会話の逐語・音声を送らない設計です。

RevenueCat は本アプリから委託された処理者です。Plus を使わない間は RevenueCat SDK を起動せず、
Plus 画面を開く、購入する、購入を復元するといった場面で使います。

## 3. ネットワークと端末

| 項目 | 内容 |
|---|---|
| 端末 | Android / iOS / iPadOS（ストア公開前） |
| 通信先 | `rika-chousa.vercel.app` / `*-aiplatform.googleapis.com` / `api.revenuecat.com`（Plus 利用時）/ Apple App Store / Google Play |
| プロトコル | HTTPS / WebSocket（443） |
| マイク | 声で説明する場合のみ。**文字入力でも使えます** |
| 通信量 | 1回10分の会話でおよそ 10〜20MB（音声を使う場合） |

### 教室で一斉に使う場合の注意

**マイクは周りの声を拾います。** 30人が同時に声で説明すると、
隣の生徒の声が混ざって会話が成立しません。

教室で一斉に行うなら、**文字入力**をお使いください。
声を使う場合は、マイク付きヘッドセットが人数分必要です。

## 4. 費用

学習の基本機能は、**1人1日2回まで無料**です。Google へのこの範囲の利用料は開発者が負担します。

会話回数の上限を外す **Plus** は任意の有料プランです。購入操作をしなければ課金されません。
学校で一括利用する場合の費用や購入管理は未設計です。導入前に利用方法を個別に確認します。

## 6. 法令についての整理

### 海外での処理

生徒の音声と文字は Google により米国で処理されます。Plus 利用時の課金管理情報は RevenueCat により米国 AWS で処理されます。

法が求める3点（移転先の国名／その国の制度／移転先の保護措置）を、
**保護者向け説明文の本文に書いています。** 「海外に送信されることがあります」だけでは
足りないためです。

### 未成年の同意

本アプリの画面には15歳以下の保護者確認手続がありますが、現在は18歳未満の利用を遮断しています。
必要な同意の方法や説明主体は、学校の設置者、利用形態、適用される法令で変わります。
**この手続は Google Cloud §20(d) の禁止を解除しません。** AI 基盤移行後も、本資料だけで
法的な結論とせず、導入前に学校設置者の個人情報保護担当と確認してください。

### 利用している AI サービスの規約

> [!danger] 現状は学校導入 No-Go
> Google Cloud Service Specific Terms §20(d) は、18歳未満向け、または18歳未満が
> アクセスする可能性が高いオンラインサービスでの生成AIサービス利用を禁止しています。
> Google Cloud Services Summary は Vertex AI API と Vertex AI Live API を
> 生成AIサービスに明示的に含めています。

| 経路 | 18歳未満向けの利用 |
|---|---|
| Gemini API（開発者向け） | **禁止**（規約に明記） |
| **Vertex AI / Vertex AI Live（Google Cloud）** | **禁止**（Cloud 固有規約 §20(d)） |

このアプリは現在 **Vertex AI** を使っているため、中高生向け製品である限り、
年齢ゲートを追加しても利用可能にはなりません。学校の承認や保護者同意も、
個人情報保護上の手続として必要になり得ますが、Google の契約上の禁止を解除しません。

**利用可能な別プロバイダーへの移行、または Google と書面で合意した個別契約が完了するまで、
授業・実証・家庭学習で生徒に AI 会話機能を使わせないでください。**

### Google Workspace for Education をお使いの場合

Google Workspace for Education の一部エディションには、Gemini for Education と
NotebookLM を18歳未満へ有効化できる例外があります。しかし、これは Workspace 固有の例外であり、
本アプリが使う Google Cloud / Vertex AI API には適用されません。

## 7. 中身（教材）について

- 教材は**すべて自作**です。教科書や問題集からの転載はありません
- いまある単元は中学理科の **力と運動 / 力のつり合いと作用・反作用 / 圧力と浮力** の3つ
- 「力と運動」は**中学3年**の内容を含みます。まだ習っていない学年に使うと、
  「考え違いをしている」のか「まだ習っていない」のか区別がつきません
