# 初見学習者 5〜10分 pilot

## 目的

このpilotは、機能の存在ではなく、初めて触る学習者が説明を受けずに次の流れを完走できるかを確かめる。

1. 学習パスから「次」を見つける
2. 予想または固定課題に答える
3. 誤答した場合は、答えの総当たりではなく訂正を行う
4. 教材の説明と自分の考えを比較する
5. XP・クエスト・連続学習の更新を理解する
6. 次に進む課題または復習を自分で選ぶ

Store公開の可否を決める試験ではない。学習ループと画面設計の改善点を見つけるための受入試験とする。

## 対象と安全境界

- このアプリを初めて使う学習者で行う。
- 未成年の場合は、保護者または学校の手続きに従って同意を得る。
- 氏名、学校名、アカウント、顔、声、画面録画を収集しない。
- 回答本文は記録しない。観察票には操作事実と詰まった箇所だけを残す。
- 端末内モードを使用し、Friends / League / 外部通信は使わない。
- 学習者が中止を希望した時点で直ちに終了する。

## 端末条件

- Android実機とiOS実機で別々に実施する。Simulator / emulatorは実機証拠に数えない。
- クリーンインストール相当の未学習状態から開始する。
- 文字サイズは端末標準で1回、200%で別途画面到達性を確認する。
- Speakingを含める回は、マイク権限の許可・拒否を別セッションで確認する。
- Story読み上げは、再生中の場面遷移、戻る、バックグラウンド移行で停止するかも確認する。

## 進行

観察者は「自由に始めてください」とだけ伝える。UIの場所、正答、戻り方は教えない。

1. アプリ起動から学習パスを開く。
2. 最初の利用可能ノードを開始する。
3. 1回は固定課題を意図的に誤答してもらう。
4. 訂正と比較を終え、パスへ戻る。
5. 報酬と次の利用可能ノードを確認する。
6. 学習者が次に何をしたいかを自分の言葉で答える。

## 観察票

回答内容ではなく、次だけをセッション単位で記録する。

| 項目 | 記録 |
|---|---|
| OS / 端末区分 | Android実機 / iOS実機 |
| 開始から最初のノード開始まで | 秒 |
| 開始から比較完了まで | 分・秒 |
| 開始からパス復帰まで | 分・秒 |
| 自力で次ノードを見つけた | はい / いいえ |
| 誤答後に総当たりせず訂正できた | はい / いいえ |
| 報酬の意味を説明できた | XP / 結晶 / 連続学習 / 不明 |
| 操作が止まった画面 | 画面名と操作だけ。回答本文は書かない |
| 観察者の助言回数 | 回 |
| もう1問やりたい | はい / どちらでもない / いいえ |
| 中止理由 | 操作 / 内容 / 所要時間 / 端末 / その他 |

## 初回受入基準

- 5〜10分の範囲で、学習パス開始から比較、報酬確認、次候補の発見まで完走する。
- 正解を開示する前に固定回答が成立する。
- 誤答しても別の選択肢を順番に押すだけでは先へ進めない。
- 観察者が正答や操作位置を教えずに完走できる。
- 戻る、文字サイズ200%、マイク拒否のいずれでも行き止まりにならない。
- 画面、Semantics、保存領域、ログのどこにも回答本文・録音・認識候補が残らない。
- 1件でも重大な行き止まり、正答先出し、回答保存、誤った学習説明があれば不合格とし、修正後に最初から再実施する。

「面白い」「飽きない」は1回のpilotで断定しない。所要時間、助言回数、再挑戦意向を残し、複数回で同じ中断点が出た場合にUIまたは教材を直す。
